## Featured projects

### 💄 [Zef Beauty](https://github.com/dotschmann/zef-beauty)

A responsive website and enquiry system for a real hair and makeup business in Ghana.

**Built with:** HTML, CSS, JavaScript, Python, Flask, SQLite

The project combines responsive frontend development with a JSON API, server-side validation, SQL persistence, and a Git feature-branch workflow. The connected backend is currently being developed on `feature/enquiry-api`.

### 🤖 [Wachroboter ROS 2](https://github.com/dotschmann/wachroboter-ros2)

A two-robot guard/visitor mission built with **ROS 2 Jazzy and C++**.

The original version was developed for physical Volksbot robots in a university robotics lab. The repository also includes a lightweight simulation backend so the mission logic can be demonstrated without access to the lab hardware.

**Built with:** C++, Python, ROS 2, `NavigateToPose`, RViz, TF, odometry

The project demonstrates robot coordination, ROS 2 topics and actions, mission-state logic, and portable simulation.
